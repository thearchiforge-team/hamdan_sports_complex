## 4. Mandatory Coding Agent Rules (Antigravity / VS Code / Cursor / Claude Code)
1. **Contract-First API Discipline:**
   - Never invent undocumented REST endpoints or alter request/response field names unilaterally.
   - All HTTP routes and DTOs under `src/` MUST match `specs/openapi.yaml` (OpenAPI 3.1).
2. **Schema & Migration Discipline:**
   - Never modify database tables without a corresponding migration in `db/migrations/`.
   - Every table storing PII/PCI data MUST preserve KMS AES-256 encryption at rest and audit timestamp columns (`created_at`, `updated_at`).
3. **Enterprise Tech Radar Prohibitions (DO NOT INSTALL OR USE):**
   - ❌ Memcached (use Redis 7 Cluster with TLS)
   - ❌ MySQL 5.6/5.7 (use PostgreSQL 16 or Aurora 8.0)
   - ❌ Plaintext HTTP / TLS 1.0 / TLS 1.1 (enforce TLS 1.3 / mTLS)
   - ❌ Long-lived static IAM access keys in source code
4. **Zero-Trust Security & Secrets:**
   - Never hardcode secrets, connection strings, or API keys. Read configuration from environment variables documented in `.env.example`.
   - Enforce structured JSON logging with `trace_id` correlation and OAuth2/OIDC JWT validation on all protected routes.
